# Support

For usage questions and reproducible defects, open an issue at
<https://github.com/judenimo/KittenIO/issues>.

Before reporting a problem:

1. Confirm the exact versions in the [compatibility matrix](docs/compatibility.md).
2. Run `kittenio doctor` and include its output; it is designed not to reveal
   the pairing token.
3. Include the KittenIO release, Python version, operating system, relevant
   error text, and minimal reproduction steps.
4. Remove tokens, personal paths, and private gameplay data from attachments.

Unsupported KSA or StarMap builds, modified proprietary assemblies, and custom
protocol forks are outside the v0.1.0 support boundary. Security reports belong
in the private channel described in [SECURITY.md](SECURITY.md), not a public issue.
